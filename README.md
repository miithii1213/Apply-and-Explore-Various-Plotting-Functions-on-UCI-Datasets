# 🌸 Apply and Explore Various Plotting Function on UCI Datasets

A **Data Visualization and Exploratory Data Analysis** project that explores the **Iris Dataset** using different plotting functions. The project provides a simple **Iris Dataset Explorer** interface to visualize and understand patterns in the dataset.

---

## 📌 Project Overview

Data visualization is an important part of data science because it helps transform raw data into meaningful visual information.

This project demonstrates the application of different plotting techniques on the **Iris Dataset**. It allows users to explore the dataset using multiple visualization methods and understand distributions, comparisons, relationships, and correlations between features.

---

## 📊 Visualizations

The application provides the following plotting functions:

### 1. 📈 Bar Chart

Used to compare values across different categories.

### 2. 📊 Histogram

Used to understand the distribution and frequency of numerical features.

### 3. 🔵 Scatter Plot

Used to study relationships between two numerical variables and identify patterns or clusters.

### 4. 📦 Box Plot

Used to visualize the median, quartiles, spread and possible outliers in the data.

### 5. 🥧 Pie Chart

Used to represent the proportion of different Iris species.

### 6. 🌡️ Correlation Heatmap

Used to visualize the correlation between numerical features.
